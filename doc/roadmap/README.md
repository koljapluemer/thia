# Roadmap

Plans and design discussions. These notes describe proposals, not current behavior.

- [[deck-authoring]] — a local deck authoring app, generation pipelines, and eventual publishing
- [[gestalt-definitions-as-data]] — models separated from views (built); distributing definitions as data (open)
- [[concept-model]] — proposed inventory sets, navigation, and concept-level estimates
- [[outlines]] — MVP plan: curricula (Niedersachsen maths, US Common Core) and guides as outlines on the site, views found through concepts
- [[concept-naming]] — prefixes in concept names: identity qualifiers yes, field classifications no; canonical English
- [[web-first]] — one web app, the browser as home, an account that syncs encrypted; desktop as optional tools
- [[teacher-app]] — a hosted app where teachers make views, publish them to students, and offer them for loops (MVP built)
- [[one-workshop]] — the three workshops as one behind the login; the agent asks; lessons of several views
